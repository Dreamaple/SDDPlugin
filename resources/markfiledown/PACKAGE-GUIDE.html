What To Publish

Publish the whole markfiledown-0509/ folder. The folder vendors both source skills under engines/, so downstream projects do not need sibling copies of doc-pre-allinone-skill-0508/ or efm-multidoc-markdown-bundle/.

How To Run

.\markfiledown-0509\run.ps1 -InputPath ".\docs" -OutputRoot ".\outputs\markfiledown-0509"

For explicit files, pass a PowerShell array:

$files = @(".\a.pdf", ".\b.docx")
.\markfiledown-0509\run.ps1 -InputFile $files -OutputRoot ".\outputs\markfiledown-0509"

Fixed Image Link Strategy

The previous promoted Markdown copied an engine final.md to the integrated document root while leaving links like artifacts/pages/page-0001-full.png. Those links were relative to the engine output folder, so they broke after promotion.

The runner now rewrites local links during promotion. For example, media-center page images now point to paths like:

engine-results/doc-pre/j90k-ux-v0-2-0-20240920-c56211c8/artifacts/pages/page-0001-full.png

The current five-document run produced 0 broken promoted Markdown links across all five link-check-report.json files.

Quiet Execution

The package contains no executable calls to explorer.exe, Start-Process, Invoke-Item, os.startfile, or Shell.Application. It prints paths and writes reports only. If a host opens File Explorer after a task, that behavior should be disabled in the host wrapper; the replacement is to print the report path and let the user open it explicitly.
